What Was Checked

Each commit within the audit window was verified against the following criteria:

  • Commit signing: Every commit must have a valid GPG or SSH signature
  • PR traceability: Every commit must be the merge result of an approved pull request
  • CI integrity: Required status checks must have passed before merge
  • No post-merge tampering: No commits pushed after PR was merged or closed
  • Commit message originality: No replicated commit messages (social engineering indicator)
  • Dependency provenance: New/updated dependencies checked for release date and yank status
  • Renovate cooldown enforcement: Adoption timing verified against configured minimumReleaseAge
  • Known vulnerability scan: All packages checked against OSV.dev
  • Branch protection stability: No modifications to branch protection during the window
  • Post-approval PR integrity: No pushes after the last review approval
  • Human review requirement: Every merged PR must have at least one human approval
  • Squash/merge via GitHub UI: Accepted when they are the merge commit of a reviewed PR
  • OpenSSF Scorecard: Workflow presence and published scores verified
